# Forma — Project

URL:- https://forma-studio-puce-eight.vercel.app

A fictional creative studio portfolio built with React, TypeScript, semantic HTML and CSS. Includes category filters, native dialog previews with Escape/keyboard support and focus restoration, responsive navigation, reduced-motion support, and six illustrative project briefs.

## Local development
npm install
npm run dev

## Production
npm run build
npm run preview

Deploy the Vite output directory `dist` to Vercel. This project is frontend-only. Concept work is not claimed as commissioned client work. Reference photographs sourced from Unsplash (architecture, portrait, interiors, landscape and furniture); no client testimonials or outcome metrics are asserted.
